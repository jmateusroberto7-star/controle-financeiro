# Controle Financeiro Pessoal
Um aplicativo simples para registrar receitas e despesas e acompanhar seu saldo mensal.

## Sobre o Projeto
Este projeto foi desenvolvido como atividade do curso de programação. O objetivo é ajudar no controle das finanças
pessoais de forma fácil e rápida.

## Funcionalidades
Adicionar transações (receitas e despesas)
Excluir transações da lista
Calcular saldo automaticamente
interface simples e responsiva

## Tecnologias Utilizadas
- HTML5
- CSS3
- Java Script

  .Abra o arquivo `site.html` no navegador
